And any other game

The generic ripper surveys a folder and tells you what is in it: which archives it can open, which need a specialist tool, and which it does not recognise. It unpacks Zip-family archives (including the .pak and .obb files that are really zips), Valve VPK, Quake PAK and Doom WAD.

For containers nothing can parse, it can carve known file signatures straight out of the bytes and recover the textures and audio stored inside.

What carving cannot do. Carved files have no names and no folder structure, and anything that was compressed inside its container will not appear — only data stored whole can be recovered this way. Ripper says which of the two you are getting rather than presenting them as the same thing.

Where a format genuinely needs a dedicated tool — Unity bundles, encrypted Unreal paks, Bethesda archives — Ripper names the tool that handles it instead of writing files that look extracted and are not.

Want a game added?

There is a Request a game button on Ripper's front screen. Name the game, say what you can see in its folder, and it goes straight to the inbox. Requests with the store page and a list of file extensions are the ones that get built first.

Updates itself

Ripper checks for a new version when it opens and offers to install it. The download is verified against a published checksum before anything runs — if it does not match, it is deleted rather than executed.

Get Ripper

One file, about 67 MB. It carries its own copy of everything it needs, so there is no runtime to install first.

Download Ripper
  1. Run Ripper-Setup.exe
  2. Choose Install for shortcuts and updates, or Just run it to use it portably
  3. Pick a game, point it at the folder, extract

Installing is per-user and needs no administrator prompt. Windows SmartScreen may warn about a new download — the checksum for every release is published in update.json.

Fair use

Ripper reads games you already own, on your own machine. It does not download game data, break copy protection, or ship anyone else's assets. What you extract stays yours to deal with — respect the rights of the people who made it.
