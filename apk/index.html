Useful without a PC

The full Rabbit Kit starts on your phone.

Local Android tools are the main app. Linked PC is an optional feature for the jobs that genuinely need Windows.

01Notes, links and clipboard

Keep local notes, save links, export text, share content, and work with your phone clipboard.

02Files and creation

Pick files securely, preview images, edit photos, draw pixel art, convert units, format text and generate hashes.

03Android app manager

Browse launchable apps, open them, inspect Android settings, or request a normal uninstall.

04Vibration Lab

Adjust intensity and duration, then play steady, pulse, heartbeat, or SOS patterns.

05Torch and Morse

Translate typed phrases into repeatable Morse flashes with adjustable speed and supported torch strength.

06Optional linked PC

Connect only when wanted for HD remote control, typing, Explorer, Steam games, touch gamepad, and every Windows Rabbit Kit tool.

Three steps

Install and start locally.

DownloadTap Download above, then open RabbitKit-Android.apk from your browser's Downloads list.
Allow this sourceIf Android asks, allow your browser to install this one downloaded app, then press Install or Update.
Open Rabbit KitChoose This phone immediately. Linked PC remains optional and can be paired later from inside the app.
Local by default. Phone notes and preferences remain on the device until you share them. If you enable Linked PC, its picture, input, and clipboard stay between paired devices on trusted Wi-Fi or USB. Do not forward the PC remote ports or use them on an untrusted public network.
